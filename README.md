# BrailleAtelier · 盲文教材转录和校对工具

BrailleAtelier 是一个完全运行在浏览器中的盲文教材工作台。它把课文原文逐行转换为盲文单元，允许编辑规则集、标记可疑规则、批量修正同类问题，并记录本地版本快照。

## 功能

- 课文拆分：粘贴整篇课文后按换行和句末标点自动拆行，也可手动新增、编辑、拆分或删除行。
- 多规则集：内置 UEB 教学规则、通用文学盲文和逐字拼读三套规则，可即时切换。
- 转写模型：支持字母、数字、标点、词级缩写、分词空格和跨行连字符。
- 逐行校对：每行同时显示原文、拆分后的盲文单元、可疑项和校对状态；可上移/下移调整行序。
- 排版预览：每行格数与每页行数可调（10–60 格 / 8–40 行），转写后自动分页；放不下的连续文本词内断行，后半段仍按原行校对，并在页首标注“续接上页·同词未完”等续接标记。
- 分页调整：可逐格左右移动断点、把整行移到下一页；手动断点与移页设置随项目保存，重开或刷新后保留，也可一键清除恢复自动分页。
- 重算失效：修改原文、规则或行序后自动重新转写与分页；格流、行序位置或分页坐标发生变化的已批准行会回到待核对，纯版心/分页调整不影响批准状态。
- 问题处理：按同类规则聚合问题，可停用问题规则并批量修正全部受影响行。
- 规则编辑：启停缩写、修改原文与输出、标记可疑规则、新增自定义规则，并重新检查全文。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + Enter` 批准并进入下一行、`J/K` 或上下方向键切换行。
- 版本与导出：最多保留 20 个浏览器本地版本（含版心与分页调整），可恢复版本；支持文本导出和按当前版面输出的 A4 打印版导出（页页分隔、页首续接标记、行尾词内连字符）。
- 本地持久化：刷新或离线后继续编辑，草稿保存在 `localStorage`。

## 技术栈

- Preact 10
- TypeScript 5
- Material Web Components 2
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。项目没有硬编码宿主端口。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1010 .
docker run --rm -p 10010:80 sologsb-1010
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10010`。
